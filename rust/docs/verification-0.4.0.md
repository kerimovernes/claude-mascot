# Проверка 0.4.0 (06.11.2026)

Rust-версия оставляет только Claude. Добавлены Laptop, Stretch и LookAround:
команды меню, таймлайны и редкие idle-запуски. Старый выбор Tagilla мигрирует
в Claude без сброса FPS и масштаба; custom_atlas больше не загружается.
Исходная Python-версия в корне репозитория сохранена отдельно.

## Выполнено

- Windows x64, Rust 1.99.1, stable-x86_64-pc-windows-gnu.
- fmt, Clippy по всем targets с -D warnings, release build прошли.
- 78 тестов: 35 library, 1 binary, 41 engine regression, 1 native lifecycle.
  Тесты удалённых боевых возможностей убраны вместе с этими возможностями.
  Покрытие в процентах не измерялось.
- Проверены длительность ноутбука 10 с, коротких поз 2/2,5 с, ожидание опоры,
  отмена ноутбука на фазах открытия/печати/закрытия захватом, прыжком и потерей окна.
- Renderer проверяет разные фазы и позы. Экспортированы 30 PNG-превью;
  открытие/печать/закрытие ноутбука просмотрены визуально.
- Headless: 36 000 шагов, 600 симулированных секунд, два Claude,
  координаты и скорости оставались конечными.
- Готовый EXE после встраивания иконки прошёл нативные smoke-сеансы:
  180 кадров / 3,0003014 с при 60 FPS; 360 / 3,0001701 с при 120;
  720 / 3,0004747 с при 240. Все кадры представлены, завершение штатное.
  Это короткие проверки одного питомца; отдельный замер FPS во время ноутбука
  и новый ручной drag-бенчмарк в этом проходе не выполнялись.
- MSI собран WiX 6.0.2, валидация завершилась с кодом 0.
  Два предупреждения ICE91 относятся к намеренной установке в профиль одного
  пользователя. Извлечённый MascotExe побайтно совпал по SHA-256 с проверенным EXE.
- Локальный Defender CustomScan готового EXE: сигнатуры 1.463.155.0,
  новых совпадающих обнаружений нет, файл сохранился и хеш не изменился.
  Это результат этого компьютера, не вердикт Microsoft для старого образца
  и не гарантия отсутствия срабатываний на других компьютерах.
- Diff и текущие ссылки проверены. В изменяемых исходниках не найдено
  строк token/api_key/password/secret. Это ограниченная проверка, не полный аудит.

EXE: 1 038 848 байт.
SHA-256: 7498b8a277ecfef5265820f1b905896be6a3f1d1f5ba3470c85f184c1504a904.

## Границы приёмки

Установка/обновление/удаление MSI в пользовательском профиле, опубликованный
portable update/rollback и полная mixed-DPI матрица НЕ ВЫПОЛНЯЛИСЬ.
Бинарный публичный релиз не опубликован. Полный паритет с Python/Linux
не заявляется. Банк из 40 фраз остаётся proposed JSON; в runtime добавлены
только контекстные реплики трёх новых действий.

Артефакты и JSON traces сохранены в отдельной папке outputs/0.4.0.
Исторические EXE и образец Defender 0.1.0 не перезаписывались.
