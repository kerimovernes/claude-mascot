# Обновления Rust-версии

Rust-версия проверяет GitHub Releases репозитория `kerimovernes/claude-mascot`.
Проверка выполняется при запуске и затем примерно раз в шесть часов, если
включена «Автопроверка обновлений». Проверка не устанавливает файлы и не
перезапускает программу. При найденной версии приложение сначала спрашивает
подтверждение; без согласия скачивание и замена исполняемого файла не
происходят. Проверку можно запустить вручную из меню «Проверить обновления».

Загрузчик принимает только ожидаемый exe GitHub Release и сверяет SHA-256
загруженного файла с обязательным digest SHA-256, который GitHub сообщает для
этого release asset. Он не запускает команды,
скрипты обновления или произвольные адреса из метаданных. После проверки новый
exe подготавливается рядом с текущим; замена выполняется отдельным локальным
helper-процессом после завершения маскота. Если замена не удалась, helper
возвращает предыдущий exe. Настройки и пользовательские файлы не входят в
обновление и остаются на месте. Обновление работает от имени текущего
пользователя и не требует прав администратора.

Релиз собирается из исходников при публикации тега `rust-v<версия Cargo>`.
Workflow проверяет форматирование, тесты и clippy, собирает Windows x64 exe,
прикладывает точный файл `claude-mascot-windows-x64.exe` для обновлятора и ZIP
для ручной установки. ZIP содержит `claude-mascot.exe`, `README.md`,
`Install.ps1`, `Uninstall.ps1`, а также документацию по архитектуре и
обновлениям. `SHA256SUMS` позволяет самостоятельно проверить exe и ZIP.
Релизы из pull request не публикуются. Workflow требует совпадения тега с
версией в `rust/Cargo.toml` и проверяет, что тег уже существует в GitHub.

Автопроверка включена по умолчанию; её можно отключить пунктом меню
«Автопроверка обновлений». Для сборки собственного форка задайте
`MASCOT_UPDATE_REPO=владелец/репозиторий` во время компиляции. Публичные
релизы официального репозитория используются по умолчанию.

Обновлятор добавлен в Rust-версию 0.2.0. Он не входит в старый бинарник 0.1.0.
