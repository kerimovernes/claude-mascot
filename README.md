# Claude-маскот

## Нативная Rust-версия для Windows

В каталоге [`rust/`](rust/README.md) — отдельная Windows-версия с нативными
прозрачными окнами, независимым движком поведения, двумя персонажами, треем
и JSON-настройками. Сборка даёт переносимый `.exe` без Python.
Инструкции и ограничения: [`rust/README.md`](rust/README.md).
Архитектура: [`rust/docs/architecture.md`](rust/docs/architecture.md).
Проверки: [`rust/docs/verification.md`](rust/docs/verification.md).

## Исходная Python-версия

Маленький пиксельный чел, который живёт у тебя на рабочем столе:
гуляет, спит, лазает по окнам, подглядывает за видосами и ловит курсор.

Два персонажа на выбор (правой кнопкой → «Персонаж»):

**Клод** — оранжевый и добрый.

![Клод](preview.png)

**Тагилла** из Escape from Tarkov — носится с кувалдой и крушит окна
(трещины и осколки — только картинка, сами окна он не трогает).

![Тагилла](preview_tagilla.png)

## Установка на Windows

1. Распакуй архив (правой кнопкой → «Извлечь всё»). Запускать прямо из zip не надо.
2. Открой папку `claude-mascot` и дважды кликни **`install.bat`**.
3. Если Python не установлен, установщик предложит поставить его сам через winget (жми `Y`).
   Если winget нет — поставь Python с [python.org](https://www.python.org/downloads/),
   в установщике поставь галочку **«Add python.exe to PATH»**, и запусти `install.bat` ещё раз.
4. Установщик спросит про автозапуск — ответь `y`, если хочешь, чтобы маскот появлялся при входе в Windows.

Маскот упадёт сверху на экран, на рабочем столе и в «Пуске» появится ярлык «Claude-маскот».
Удалить — дважды кликни `uninstall.bat`.

> Windows может показать «Windows защитила ваш компьютер» — это из-за того, что файл скачан из интернета.
> Нажми «Подробнее» → «Выполнить в любом случае».

## Установка на Linux

```bash
cd claude-mascot
./install.sh              # поставить и запустить
./install.sh --autostart  # то же + запуск при входе в систему
```

Удалить: `./uninstall.sh`. Лазать по окнам и подглядывать он умеет только на **KDE Plasma 6** —
на других окружениях (GNOME и т.д.) просто гуляет по низу экрана.

## Управление

| Что сделать | Что будет |
|---|---|
| Тащить левой кнопкой | Перетащить; если отпустить с размаху — полетит |
| Клик | Погладить (сердечки) |
| Двойной клик | Прыжок |
| Правая кнопка | Меню: гулять / сидеть / спать / залезть на окно / крушить (Тагилла) / бегать за курсором / сменить персонажа / позвать друга (выбрать кого) / выход |

## Что он умеет сам

- Запрыгивает на окна, гуляет по ним и катается вместе с окном.
  Потрясёшь окно или резко дёрнешь — слетит.
- Карабкается по боковым краям окон и сидит на краю, свесив ноги.
  Бросишь его рядом с краем окна — схватится.
- Когда в браузере играет видео — прячется сбоку за окном и подглядывает.
- В режиме «Бегать за курсором» догоняет курсор и **висит на нём**.
  Стряхнуть можно только сильной тряской мышью. Клики при этом работают как обычно.
- В полноэкранных играх прячется, чтобы не мешать.
- Засыпает, только когда ты отошёл от компьютера (минуту не трогаешь мышь и клавиатуру),
  и просыпается, как только вернулся.
- Тагилла сам находит окна, подбегает и лупит по ним кувалдой — по окну расходятся трещины
  и летят осколки, через несколько секунд всё исчезает. Окна при этом работают как обычно.
- Если позвать Тагиллу и кого-то ещё (ПКМ → «Позвать друга»), Тагилла звереет и гоняется
  за ним с кувалдой. Тот удирает, прыгает через Тагиллу и прячется на окнах, но его всё равно
  догоняют — и он улетает кувырком. Спрятаться можно на курсоре… но ненадолго.
  Иногда (в 20% ударов) жертва ловит кувалду руками — и кувырком улетает уже Тагилла.
  Буйство находит на Тагиллу приступами — раз в 10 секунд … 2 минуты, на полминутки.
  Взбесить его сразу или насовсем можно в его меню («Взбеситься сейчас», «Буйство без перерыва»).
- Если включить Тагилле «Бегать за курсором», он не хватается за курсор, а лупит по нему
  кувалдой — и курсор улетает в сторону. (На Linux для этого нужен доступ к `/dev/uinput` —
  обычно он есть, если стоит Steam; на Windows работает всегда.)

## Переделать под себя через Claude

В папке лежит `CLAUDE.md` — инструкция для Claude Code. Открой эту папку в Claude Code и просто попроси, например:

- «Сделай вместо него котика / лягушку / Пикачу»
- «Пусть говорит по-английски» или «добавь фраз»
- «Пусть бегает быстрее» / «пусть труднее стряхивать с курсора»
- «Добавь, чтобы он иногда танцевал»

Claude сам разберётся, где что менять, проверит позы на картинке и перезапустит маскота.
